# IPL Player Scouting & Analytics System

A Python-based IPL player scouting system that analyzes player performance, ranks players, compares players, identifies team requirements, and generates scouting insights using data analytics.

## Project Objective

The goal of this project is to help cricket teams identify and evaluate players using performance-based data.

The system analyzes IPL batting data and generates scouting scores, categories, rankings, comparisons, and visual insights.

## Key Features

- Player scouting and performance analysis
- Player ranking based on scouting score
- High strike-rate player identification
- High run-scorer identification
- Power-hitter identification
- Player category classification
- Smart player search
- Team requirement engine
- Player comparison
- Data visualizations
- Scouting dashboard

## Scouting Methodology

Players are evaluated using:

- Total Runs
- Strike Rate
- Boundary Percentage
- Scouting Score

Players are classified into:

- Developing Player
- Aggressive Batter
- Experienced Performer
- Consistent Performer

## Visualizations

- Top 10 IPL Players by Scouting Score
- Runs vs Strike Rate
- Player Category Distribution

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Data Analysis
- Data Visualization

## Future Improvements

- Add bowling and all-rounder analysis
- Add machine learning-based player prediction
- Build an interactive Streamlit dashboard
- Add IPL season-wise analysis
- Add team-wise squad recommendations
